# Final Project 

viral sound propagation machine - build a network of sound nodes that "infect" each other with musical patterns. each node is a physical device with speakers/mics that listens to neighbors and mutates what it hears before retransmitting. patterns evolve and die out like biological systems. technical: mesh networking protocols, real-time audio analysis, genetic algorithms for pattern mutation, custom pcb design for each node
